# Simple Interest Calculator

This project is a simple interest calculator that calculates the interest earned or charged on a principal amount over a specified period, using an annual interest rate.

## Inputs

- **Principal (p):** The initial amount invested or borrowed.
- **Annual interest rate (r):** The yearly interest rate, expressed as a percentage.
- **Time (t):** The duration of the investment or loan, in years.

## Calculation

```text
Simple interest = (p × r × t) / 100
Total amount = p + simple interest
```

For example, a principal of 1,000 at an annual interest rate of 5% for 2 years produces 100 in simple interest and a total amount of 1,100.

Simple interest is calculated only on the original principal; it does not compound.

## Project scope

This educational project practices Git and GitHub workflows while developing a Bash calculator that accepts the principal, annual interest rate, and time period as user input.
