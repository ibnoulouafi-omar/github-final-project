# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Open an issue to report a bug or suggest an improvement. Include clear details and steps to reproduce any problems.
2. Fork the repository and create a branch for your changes.
3. Make your changes and verify that they work as expected.
4. Submit a pull request describing your changes and linking any related issue.

Please follow the [Code of Conduct](CODE_OF_CONDUCT) when participating in this project.
